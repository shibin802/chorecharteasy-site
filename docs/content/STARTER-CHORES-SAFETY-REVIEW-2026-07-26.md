# Starter Chores 年龄与安全审查

- 项目：ChoreChartEasy
- 日期：2026-07-26
- 状态：`NEEDS_OWNER_REVIEW`
- 范围：免费 Maker 的 4 个年龄带 starter tasks 和 Morning starter
- 边界：来源化产品编辑审查，不是儿科、职业治疗、医疗或法律意见

## 1. 审查依据

### American Academy of Pediatrics / HealthyChildren.org

来源：

- [Age-Appropriate Chores for Children](https://www.healthychildren.org/English/family-life/family-dynamics/communication-discipline/Pages/Chores-and-Responsibility.aspx)
- [5 Common Household Products that are Dangerous to Curious Toddlers](https://www.healthychildren.org/English/safety-prevention/at-home/Pages/5-Common-Household-Products-that-are-Dangerous-to-Curious-Toddlers.aspx)

2026-07-26 实际读取原文，核心依据：

- Preschool children 可以参与简单 household tasks；目标是参与和学习，不应期待完美结果。
- 5–7：铺床、摆/清餐桌、收玩具、衣物入篮、扫地、分类衣物等。
- 8–10：可在上述基础上准备自己的简单零食、收自己的衣物等。
- 11–12：可扩展到卸洗碗机、洗/叠衣物、在监督下做简单餐食等。
- 应一次引入少量任务、写清楚期望、建立固定 routine、提供支持和监督，并保持现实预期。
- 清洁剂和洗衣产品可能有毒，应保留原容器并放在儿童接触不到的位置。

## 2. 产品安全规则

所有 starter 均遵守：

1. 使用具体、可观察的完成动作，不用 `clean everything`、`manage` 等模糊任务。
2. 不分配清洁剂、洗衣凝珠、药品、刀具、热表面、火源、重物、高处或攀爬任务。
3. 餐具限定为 unbreakable/safe dishes，并要求成人批准。
4. 食物准备限定为 simple snack，并要求成人批准；不暗示可独立使用刀具或热源。
5. 年龄只是起点；成人必须按能力、家庭环境和监督条件调整。
6. 不承诺行为改善、发展效果、绝对安全或适合每个孩子。

## 3. 最终 Starter 合同

### Ages 3–4

| Task | 判断 |
|---|---|
| Put toys in a basket | 简单、可见、低风险 |
| Place clothes in the hamper | 简单个人责任；不接触洗衣产品 |
| Carry napkins to the table | 使用轻软物品，不含餐具 |
| Put books on a shelf | 仅低处可触及书架；成人调整环境 |
| Wipe a small spill with adult help | 必须成人帮助；只处理小量普通液体，不使用清洁剂 |

### Ages 5–6

| Task | 判断 |
|---|---|
| Make the bed | AAP 5–7 示例；接受儿童标准 |
| Put clothes in the hamper | AAP 5–7 示例 |
| Help set the table | 使用 `Help`，成人选择安全物品 |
| Pack toys after play | AAP 5–7 put toys away |
| Put school items by the door | 轻物品、可观察结束 |

### Ages 7–9

| Task | 判断 |
|---|---|
| Make the bed | AAP 5–7 起可做 |
| Pack the school bag | 成人可按学校和负重情况复核 |
| Clear the table | AAP 5–7 示例；成人排除热/尖/易碎物品 |
| Put away personal laundry | 对齐 AAP 8–10 `put away their own laundry`；替代较宽的 `Fold simple laundry` |
| Sweep a small area | 对齐 AAP 5–7 sweep floors，范围缩小 |

### Ages 10–12

| Task | 判断 |
|---|---|
| Sort and fold personal laundry | 比 `Manage personal laundry` 更具体；不接触洗衣产品/机器设置 |
| Unload unbreakable dishes with adult approval | 比 `Load or unload safe dishes` 更明确；排除尖锐、热和易碎物品 |
| Prepare a simple snack with adult approval | 对齐 AAP 8–10 simple snack；成人决定工具/食材/allergen 安全 |
| Empty a small wastebasket | 替代 `Take out household trash`，降低重量、尖锐物和室外风险 |
| Reset one shared room | 仅整理可安全触及的普通物品 |

### Morning starter

- Ages 3–6 使用 `Brush teeth with adult help` 和 `Pack what you need with adult help`。
- Ages 7–12 保留简短独立文本，但成人仍负责按实际能力调整。

## 5. 页面披露合同

页面必须持续显示：

- `Age-based starting ideas. Adult review required.`
- 年龄只是起点，成人需按能力、环境和监督调整。
- 避免清洁化学品、尖锐工具、热表面、重物和攀爬。

- [ ] 不需要删除或替换某个家庭文化/生活方式相关任务。
