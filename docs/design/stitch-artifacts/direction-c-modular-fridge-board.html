Frequently asked

Is it really free? expand_more
Yes. The core chore chart maker is 100% free with no sign-up required. We make money through our premium template packs for power users.
Which paper size should I use? expand_more
Our tool supports both US Letter (standard in North America) and A4 (International standard). Choose the one that matches your printer paper.
What if I have multiple kids? expand_more
You can create separate charts for each child or use our "Multiple Kids" beta layout which puts them all on one page.
