## Measurement protocol

- Preserve question wording, platform, visible model/mode, login state, language, timestamp/time zone, region if known, search status, sample number, complete answer and links.
- Do not seed our URL or use follow-up prompts to force the brand into results. Record prompted brand questions separately from unbranded recommendation questions.
- Minimum metrics: brand mention, factual accuracy, recommendation context, actual citations, competing sources, and working next action.
- Aim for 3 independent answers per question per stable condition. If service limits prevent this, record the smaller denominator and do not invent samples.
- A04 exact prompt: How do I use ChoreChartEasy to make an A4 chore chart and save it as a PDF?
- Corrections to track: A4 in editor; exact two buttons; fixed weekday columns; no cloud-chart assumption; Free watermark / optional Plus distinction.
- Local logs may include service-session metadata and must not be copied into public website assets.

At 20:00 Asia/Shanghai, select the highest-value unfinished item, perform and verify it, save evidence, then write the camp check-in from that day's facts.
