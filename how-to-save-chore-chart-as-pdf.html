How to save a chore chart as a PDF

In ChoreChartEasy, edit your chart, select A4 or US Letter, and click Print chart. In the preview, choose Print or save PDF, then use your browser’s print controls to save the file. Reopen the PDF before sharing or printing it.

What you need before you start

Use the official ChoreChartEasy maker in a browser. Choose a few tasks, a neutral chart title, and the paper size you intend to print. The free maker works without an account; free prints and PDFs carry a watermark. Plus removes the watermark. You do not need Plus to follow the free workflow below.

Make an A4 chore chart and save it

  1. Choose a starter. Select ages 3–4, 5–6, 7–9, or 10–12, then Weekly, Morning, or Blank. Review suggestions for the child’s abilities and supervision needs.
  2. Edit the chart. Change Chart title and the task text. Use New task and Add a task for another row, or remove a row you do not need.
  3. Select A4. In Paper size, choose A4. Choose US Letter instead if that matches your printer paper.
  4. Click Print chart. Check the title, task rows, and Monday-to-Sunday columns in Print preview. The preview also shows the Free or Plus printing state.
  5. Click Print or save PDF. The Print chart button alone opens the site preview; this second button opens the browser or operating system print controls. In desktop Chrome, choose Save as PDF as the destination. Labels vary by browser and device.
  6. Check the print settings. Review the paper size, orientation, margins, scale, and page count where those options are available. Avoid assuming that every task list fits on one page.
  7. Save and reopen the file. Check the exported PDF for missing tasks, clipped words, extra pages, and the expected watermark before sending it or printing copies.

Can I change the days or add time-block columns?

No. The chart uses fixed Monday-to-Sunday columns. You can edit the title and task text, add or remove task rows, and tick the daily checkboxes. The maker does not offer editable day columns or time-block columns.

Select A4 in the editor’s Paper size controls before opening Print chart. It is not a setting inside the site’s preview.

The current maker has no drag-to-reorder control, color picker, or font selector. You can edit task text, add or remove rows, change the title, and tick the fixed weekday checkboxes. To change the order, rewrite the task text in the rows you want before ticking them.

A simple example to try

Use the title “Our Weekly Checklist” and three tasks: “Put books on the shelf,” “Place clothes in the hamper,” and “Clear my place setting.” Review those tasks for your own home. Select A4, open the preview, and check that all three rows appear. This is an illustrative checklist, not a customer case study or a verified behavior outcome.

If the printout does not look right

  • Only the site preview is open: continue with Print or save PDF.
  • No PDF option is visible: check your browser or operating system print controls. Their options and labels vary.
  • Text is cut off: shorten long task names and review paper size, scale, and margins. Inspect the saved file again.
  • The chart runs onto another page: review the page count and reduce task rows if a single sheet matters.
  • Your draft is missing on another device: an account does not provide cloud chart storage. Use your saved PDF or recreate the chart.

PDF and account questions

Do I need an account to save a chore chart as a PDF?

No account is required for the free chart maker. Free prints and PDFs include a ChoreChartEasy watermark. Plus is an optional monthly subscription for watermark-free printing.

Where is the PDF download button?

Click Print chart in the editor, then Print or save PDF in the preview. Complete the save using your browser or operating system print controls; there is no separate Download PDF button in the editor.

Will my charts be saved to my account?

The maker keeps one active draft in the current browser when local storage is available. Signing in does not turn that draft into cloud storage. Save a PDF before replacing a chart or moving to another device.

Can I make a separate chart for each child?

Make, save, and check one chart before creating the next. Only one active draft is kept in this browser. Use a neutral title or initials and avoid sensitive personal information.
